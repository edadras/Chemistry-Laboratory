# 🧪 آزمایشگاه شیمی هوشمند (Chemistry Laboratory)

یک موتور محاسباتی آزمایشگاه شیمی که روی **RDKit** ساخته شده و قابلیت‌های زیر را
از طریق یک **رابط وب فارسی** و یک **API** ارائه می‌دهد:

| قابلیت | توضیح |
|--------|-------|
| 🧬 **عناصر و جدول تناوبی** | ۱۱۸ عنصر با خواص (جرم، الکترونگاتیوی، نقطه ذوب/جوش، حالات اکسایش، آرایش الکترونی، نقش زیستی) |
| ⚗️ **مدل مولکول** | ساختار، فرمول، پیوندها (یگانه/دوگانه/آروماتیک…)، حلقه‌ها، توصیف‌گرها و تصویر دوبعدی |
| 🌡️ **شرایط محیط** | دما، فشار، رطوبت، pH، کاتالیزور، حلال، نور و تکنیک‌ها (تقطیر، رفلاکس، برق‌کافت، نورکافت…) |
| 🔥 **موتور واکنش (سناریو)** | با گرفتن مواد + شرایط، محصول نهایی را پیش‌بینی می‌کند (استری‌شدن، خنثی‌سازی، احتراق، هیدروژناسیون و…) |
| 🔁 **مهندسی معکوس** | با گرفتن فرمول/داروی نهایی، آن را تا اجزای پایه تجزیه می‌کند — برش استر/آمید/اتر، **برش C–N آمین (احیای آمیناسیون)**، **برش C–C (فریدل-کرافتس/آلدُل)** و FGIها (**احیای نیترو**، اکسایش الکل) |
| ⚗️ **سنتز رو‌به‌جلوی دارو** | داروی هدف ⟶ یافتن پیش‌سازها ⟶ پیشنهاد شرایط ⟶ **تأیید بازتولید دارو با شبیه‌سازی رو‌به‌جلو** — تک‌مرحله‌ای و **چندمرحله‌ای** (تجزیه تا مواد اولیه ساده) |
| ⚖️ **موازنه‌ی استوکیومتری** | یافتن کوچک‌ترین ضرایب صحیح که معادله را موازنه می‌کند (جبر خطی روی اعداد گویا) — مثل `C₃H₈ + 5 O₂ → 3 CO₂ + 4 H₂O` |
| 🌡️ **ترمودینامیک** | تخمین ΔH (روش میانگین انرژی پیوند)، ΔG و **خودبه‌خودی بودن** واکنش — مثلاً احتراق متان ≈ −۸۰۲ kJ/mol |
| ⏱️ **سینتیک و بازده** | تخمین سرعت (آرنیوس کیفی)، بازده درصدی و برگشت‌پذیری بر اساس نوع واکنش و شرایط |
| 🌳 **نمودار درختی سنتز** | نمایش گرافیکی مسیر چندمرحله‌ای از مواد اولیه تا داروی نهایی در رابط وب |
| 🗣️ **ورودی زبان طبیعی** | کاربر سناریو را به فارسی روزمره می‌نویسد؛ سیستم مواد و شرایط را استخراج می‌کند |
| 🧮 **استوکیومتری کمّی** | مول/گرم، واکنش‌دهنده‌ی محدودکننده، بازده تئوری و درصد بازده واقعی |
| 💧 **شیمی محلول** | محاسبه‌ی pH (اسید/باز قوی و ضعیف)، pKa، انحلال‌پذیری |
| 🌡️ **تقطیر و جداسازی** | شبیه‌سازی تقطیر ساده/جزءبه‌جزء بر اساس نقطه‌ی جوش |
| ⚡ **اکسایش-کاهش و الکتروشیمی** | حالات اکسایش اتم‌ها، EMF سلول گالوانی، محصولات برق‌کافت |
| 🩺 **ADMET و تداخل دارویی** | جذب/توزیع/متابولیسم/دفع/سمیت + پایگاه تداخل داروها |
| 📈 **طیف‌سنجی** | پیش‌بینی IR، ¹H NMR و طیف جرمی (MS) |
| 🔬 **فرضیه‌سازی خودکار** | خودش ترکیب‌ها را می‌سازد، واکنش‌ها را آزمایش و محصولات را رتبه‌بندی می‌کند |
| 💊 **تحلیل دارویی** | قانون لیپینسکی، قوانین Veber، امتیاز QED، هشدارهای ساختاری |
| 🏥 **پایگاه داروها (داروخانه)** | ۴۳+ داروی شناخته‌شده با کاربرد درمانی و دسته — آنتی‌بیوتیک، ضدویروس، مسکن، قلبی-عروقی، آنتی‌هیستامین، ضدمالاریا، اعصاب و… |

## معماری

```
backend/
  chemlab/                 # هسته‌ی موتور شیمی (مستقل از وب)
    elements.py            # لایه‌ی جدول تناوبی (روی RDKit + داده‌ی غنی‌شده)
    enrichment_data.py     # داده‌ی نام و خواص عناصر (فارسی/انگلیسی)
    molecule.py            # مدل مولکول: ساختار، پیوند، توصیف‌گر، تصویر SVG
    known_compounds.py     # دیکشنری ترکیبات و داروهای شناخته‌شده
    conditions.py          # شرایط و تکنیک‌های آزمایش
    reaction_data.py       # کتابخانه‌ی قوانین واکنش (SMARTS + شرط فعال‌شدن)
    reactions.py           # موتور پیش‌بینی واکنش رو‌به‌جلو (+ معادله موازنه‌شده)
    balance.py             # موازنه‌ی استوکیومتری (جبر خطی روی اعداد گویا)
    thermo.py              # ترمودینامیک (ΔH/ΔG/خودبه‌خودی) و سینتیک/بازده
    retrosynthesis.py      # مهندسی معکوس (برش‌های C–N, C–C, FGI و…)
    hypothesis.py          # تولید و آزمایش فرضیه
    pharma.py              # تحلیل دارویی
    scenario.py            # هماهنگ‌کننده‌ی سطح‌بالا (مورد استفاده‌ی API)
  api/main.py              # سرور FastAPI + سرو رابط وب
  tests/test_core.py       # تست‌های رفتاری
frontend/index.html        # رابط وب تک‌صفحه‌ای (RTL فارسی)
```

## اجرا

```bash
pip install -r requirements.txt
cd backend
uvicorn api.main:app --reload --port 8000
# سپس مرورگر را روی http://localhost:8000 باز کنید
```

## اجرای تست‌ها

```bash
cd backend && python tests/test_core.py
```

## نمونه‌ها

- **واکنش:** `acetic acid` + `ethanol` با کاتالیزور `H2SO4` و دمای ۸۰°C ⟶ اتیل‌استات + آب
- **خنثی‌سازی:** `hydrochloric acid` + `sodium hydroxide` ⟶ NaCl + آب
- **مهندسی معکوس:** «آسپرین» ⟶ استیک‌اسید + سالیسیلیک‌اسید · «فنیل‌افرین» ⟶ آلدهیدِ آریلی + متیل‌آمین (احیای آمیناسیون)
- **سنتز دارو:** «استامینوفن» ⟶ پیش‌سازها (استیک‌اسید + پاراآمینوفنول) + شرایط، و **تأیید بازتولید** با شبیه‌سازی رو‌به‌جلو
- **فرضیه‌سازی:** با دادن `acetic acid` و `salicylic acid`، سیستم خودش **آسپرین** را کشف می‌کند

## نکته‌ی علمی

این سیستم یک **سطح اول** قابل‌گسترش است: قوانین واکنش، پایگاه ترکیبات و داده‌ی
عناصر همگی داده‌محور (data-driven) هستند و به‌راحتی قابل افزودن‌اند. پیش‌بینی‌ها
بر پایه‌ی قوانین شفاف SMARTS و توصیف‌گرهای RDKit است، نه یک جعبه‌ی سیاه؛ بنابراین
برای آموزش و کاوش مناسب است، اما جایگزین آزمایش واقعی آزمایشگاهی نیست.

## API

| متد | مسیر | کاربرد |
|-----|------|--------|
| GET | `/api/elements` · `/api/element/{z|symbol|name}` | عناصر |
| GET | `/api/molecule/{name|smiles}` | تحلیل مولکول |
| GET | `/api/molecule_svg/{name|smiles}` | تصویر ساختار |
| GET | `/api/compounds` · `/api/drugs` · `/api/techniques` | فهرست‌ها |
| POST | `/api/react` | شبیه‌سازی واکنش |
| POST | `/api/reverse` | مهندسی معکوس |
| POST | `/api/synthesize` | سنتز رو‌به‌جلوی دارو |
| POST | `/api/hypothesize` | فرضیه‌سازی |
